# Keeping study notes and code snippets

ChatGPT can't save files for you. It writes the text, and you copy it into
your own folders. Use this structure so your notes stay findable.

## Folders
- `python-notes/lecture-notes/` for lesson notes (`.md`)
- `python-notes/code-snippets/` for examples (`.py`)

## File names
Short `snake_case` topic names, with the same stem for matching files:
`scope.md` next to `scope.py`. One file per topic. If the topic exists,
add to it with a `---` separator instead of creating a near-duplicate.

## Lecture note format

```markdown
# <Lesson Title>

**Source:** <course or resource name>

<lesson content here>
```

## Code snippet format

```python
# Topic: <topic name>
# Subtopic: <subtopic or concept>
# Source: <where this came from>
# Description: <one sentence on what this demonstrates>

# --- Code ---
<snippet here>
```

When adding to an existing snippet file, separate examples with `# ---`.

## How to ask the coach
> Save this lesson as a note. (Then paste or describe the lesson.)
> Save this code as a snippet.

The coach replies with the filename and the exact text to paste.
