# Shared skills

Two versions of the same toolkit: an 8-stage workflow for building software,
data/ML and simulation projects, plus Python/Git helpers.

| If you use… | Start here |
|---|---|
| **Codex** (CLI, IDE extension, or app) and are comfortable with a repo and a terminal | [`codex/`](codex/README.md) |
| **ChatGPT** in the browser, new to AI-assisted coding | [`chatgpt-project/`](chatgpt-project/README.md) |

Not sure? Start with the ChatGPT Project. It needs no installs, and you can
move to Codex later because the workflow is the same.
