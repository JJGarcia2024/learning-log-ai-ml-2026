# Stage 0 on the AI/ML track

Source boards: `Wordsmith_AIML_Upskilling_Tracker_v2` (monthly plan, two
gates) and `Wordsmith_Essentials_Sprint_Dec31` (sprint plan, essentials list).
5 hrs/week, Jul 22 2026 → Jun 2027, hire target Q1 2027 / max Q2 2027.

## Where a new goal has to land

Every new goal must trace to one of the 8 Essentials and one sprint slot.
Don't scope work that doesn't serve the Q1 Application Gate (Dec 15, 2026) or
the Q2 Backstop Gate (Jun 30, 2027).

**The 8 Essentials** (any new goal should map to one):
1. Python (typed, tested)
2. FastAPI backend
3. Cloud fundamentals (AWS)
4. RAG + vector databases
5. LLM evaluation (Ragas/DeepEval)
6. Agentic AI (LangGraph)
7. Minimal full-stack UI (Next.js)
8. Git/GitHub hygiene + CI basics

**Sprint slots** (Jul 22 – Dec 31, 2026): S1 Python re-learn · S2 FastAPI +
packaging · S3 AWS AIF-C01 · S4 RAG flagship (repo #1) · S5 Agentic
sim-workflow agent (repo #2) · S6 Full-stack claim + application pack.

## Falsifiable-goal examples for this track

- Bad: "get good at RAG"
- Good: "Ship a LlamaIndex RAG repo over the Zotero aero/nuclear corpus with
  Ragas faithfulness + context-precision scored and a DeepEval CI gate
  green" — this is S4's gate, verbatim, and it's why it's a good goal: it's
  already falsifiable.

## Check before advancing

Does the goal already have a target-hour count and a sprint slot on
`Wordsmith_Essentials_Sprint_Dec31`? If not, it isn't scoped yet — go back to
the human, don't invent a slot for them.

## DUAL-tagged goals

If the goal is tagged `DUAL` on the tracker (serves both the Deloitte-anchor
job stack and the aerospace roadmap — e.g. Python, FastAPI, AWS), note the
aerospace payoff explicitly when scoping it, but keep the falsifiable claim
itself job-track-specific and gated by the AI/ML sprint plan. Don't let a
DUAL tag turn into two goals.
